# Aetherio Mobile

Port nativo de Aetherio para Android, creado desde cero con Kotlin y Jetpack Compose para explorar películas y series, guardar favoritos y reproducir vídeos propios o autorizados mediante una URL HTTPS directa.

Versión inicial: **0.1.0**, distribuida como versión preliminar.

Esta versión aparece en el teléfono como **Aetherio Native** y conserva su instalador `AetherioNative-debug.apk`.

- [Cómo se instala](docs/INSTALACION.md)
- [Cómo funciona](docs/FUNCIONAMIENTO.md)
- [Descarga del APK en Releases](Releases/README.md)

Concepto original: [Aetherio, de trklll](https://github.com/trklll/aetherio). Esta nueva aplicación también toma como referencia las indicaciones y referencias aportadas por el usuario; no reutiliza recursos de la aplicación anterior.
