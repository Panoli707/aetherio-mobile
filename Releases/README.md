# Descargar Aetherio

**Versión preliminar 0.4.0 (código de versión 7) | Android 7.0 o posterior | Requiere Internet**

[**Descargar Aetherio-debug.apk**](https://github.com/Panoli707/aetherio-mobile/releases/download/v0.4.1-preview.1/Aetherio-debug.apk)

Para la primera instalación, abre el APK desde el navegador o gestor de archivos y confirma la instalación. Si Android lo solicita, permite instalar aplicaciones desconocidas solo para la aplicación que abre el archivo. No desactives Play Protect.

La aplicación aparece como **Aetherio**, con el logo original. Si ya tienes Aetherio o Aetherio Native, instala sobre ella **sin desinstalar** para conservar tus datos.

Una vez instalada esta versión, busca las siguientes en **Ajustes > Actualizaciones > Buscar actualizaciones**. **Actualizar ahora** descarga el APK dentro de Aetherio, muestra el progreso y permite cancelar; al terminar, lo verifica y abre el instalador de Android para que confirmes. Si Android 8 o posterior pide permiso para que Aetherio instale aplicaciones desconocidas, la aplicación abre los ajustes del sistema; concede el permiso, vuelve a Aetherio y reintenta la instalación.

Las actualizaciones automáticas están **desactivadas por defecto** y la elección se guarda. Al activarlas, se buscan y descargan actualizaciones al abrir Aetherio, solo en redes no medidas; Android sigue exigiendo confirmar la instalación. El gestor de descargas de Android puede continuar una descarga iniciada aunque cierres la aplicación, que recupera su estado al volver a abrirse. No hay comprobaciones periódicas con Aetherio cerrada.
