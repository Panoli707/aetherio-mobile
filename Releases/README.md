# Descargar Aetherio

**Versión preliminar 0.14.5 | Android 7.0 o posterior | Requiere Internet**

[**Descargar Aetherio.apk**](https://github.com/Panoli707/aetherio-mobile/releases/download/v0.14.5-preview.1/Aetherio.apk)

El APK es una versión de lanzamiento optimizada, no de depuración.

Para la primera instalación, abre el APK desde el navegador o gestor de archivos y confirma la instalación. Si Android lo solicita, permite instalar aplicaciones desconocidas solo para la aplicación que abre el archivo. No desactives Play Protect. Si Android bloquea el archivo, detén la instalación; no la fuerces.

La aplicación aparece como **Aetherio**, con el logo original. Si ya tienes Aetherio o Aetherio Native, instala sobre ella **sin desinstalar** para conservar tus datos: se mantienen el mismo paquete y firma. Si Android indica un conflicto de firma, detén la instalación; no desinstales para forzarla.

Una vez instalada esta versión, busca las siguientes, incluidas las preliminares, en **Ajustes > Actualizaciones > Buscar actualizaciones**. **Actualizar ahora** descarga el APK dentro de Aetherio, muestra el progreso y permite cancelar. Al terminar una descarga manual o automática, lo verifica y lo deja listo, sin abrir el instalador ni los ajustes del sistema. **Debes pulsar Instalar actualización en Aetherio** para continuar. En Android 8 o posterior, si Aetherio aún no tiene permiso para instalar aplicaciones desconocidas, se abren los ajustes del sistema para concederlo; vuelve después a Aetherio y pulsa de nuevo **Instalar actualización**. **Confirma la instalación en Android** para completar la actualización.

Las actualizaciones automáticas están **desactivadas por defecto** y la elección se guarda. Al activarlas, se buscan y descargan actualizaciones, **incluidas las versiones preliminares**, al abrir Aetherio, solo en redes no medidas; instalar sigue requiriendo que pulses **Instalar actualización** y confirmes en Android. El gestor de descargas de Android puede continuar una descarga iniciada aunque cierres la aplicación, que recupera su estado al volver a abrirse. No hay comprobaciones periódicas con Aetherio cerrada.
