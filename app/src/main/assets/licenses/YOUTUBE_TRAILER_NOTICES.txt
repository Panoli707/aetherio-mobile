YouTube trailer resolver (Aetherio 0.20.1)

The Android playback pipeline is an independent adaptation of the desktop
youtube_resolve_stream flow: resolve the selected public YouTube ID locally,
then stream the resulting video+audio URL in Media3. It does not redistribute
trailers, use account cookies, remove DRM or download media files.
