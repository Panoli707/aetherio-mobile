# Cómo se instala

## Requisitos

- Un dispositivo con **Android 7.0 o posterior**.
- Conexión a Internet para descargar el APK, consultar el catálogo, buscar títulos y reproducir vídeos en línea.

## Descargar e instalar

1. Descarga [**Aetherio-debug.apk desde GitHub**](https://github.com/Panoli707/aetherio-mobile/releases/download/v0.3.2-preview.1/Aetherio-debug.apk). Comprueba que corresponde al repositorio `Panoli707/aetherio-mobile`.
2. Abre **Descargas** en el navegador o gestor de archivos del dispositivo y toca `Aetherio-debug.apk`.
3. Si Android lo solicita, permite **Instalar aplicaciones desconocidas** únicamente para el navegador o gestor de archivos que está abriendo el APK. El nombre de la opción puede variar según el dispositivo.
4. Regresa al archivo y pulsa **Instalar**. Cuando termine, pulsa **Abrir**.
5. Si lo deseas, revoca el permiso de instalación del navegador o gestor de archivos al terminar.

La aplicación aparece en el teléfono como **Aetherio**, con el logo original.

No necesitas root ni activar la depuración USB. **No desactives Play Protect**. Si Android bloquea el archivo, detén la instalación y comprueba su procedencia.

## Actualizar sin perder los datos

Si ya tienes **Aetherio** o **Aetherio Native**, abre el APK y confirma la actualización **sobre la instalación existente, sin desinstalarla**. Se mantienen el mismo paquete y firma, de modo que puedes conservar el nombre del perfil, los favoritos y los proveedores guardados.

Si Android informa de un conflicto de firma, detén la instalación y busca un APK de procedencia fiable con firma compatible. **No desinstales ni borres los datos para forzar la actualización**.

Al abrir o volver a Aetherio, la aplicación comprueba las actualizaciones publicadas en GitHub sin bloquear el catálogo. Si hay una actualización disponible, el aviso muestra la versión y la etiqueta **Versión preliminar** cuando corresponda.

- **Ver actualización** abre su página de GitHub en el navegador. Descarga allí el APK e instálalo manualmente sobre la aplicación existente.
- **Ahora no** aplaza el aviso de esa versión hasta que cierres por completo y vuelvas a iniciar la aplicación, o hasta que se detecte una más nueva.

No hay descarga ni instalación automática. Android te pedirá confirmar la instalación manual; el permiso para abrir el APK corresponde al navegador o gestor de archivos, no a Aetherio.

## Primer uso y datos guardados

Puedes explorar el catálogo, buscar títulos y guardar favoritos sin configurar proveedores. Para reproducir desde las fichas, añade un proveedor compatible en **Ajustes**; no hay fuentes preinstaladas. También puedes usar un enlace HTTPS directo propio o autorizado.

El nombre del perfil, los favoritos y los proveedores se guardan en el dispositivo. No hay cuentas ni sincronización: **desinstalar la aplicación o borrar sus datos elimina esa información**.
