# Cómo se instala

## Requisitos

- Un dispositivo con Android 7.0 o posterior.
- Internet para descargar el APK y consultar el catálogo, las fichas y las imágenes.

AetherioNative 0.1.0 es una versión preliminar. Su identificador es `com.panoli707.aetherio.nativeapp` y aparece en Android como **Aetherio Native**.

## Descargar e instalar

1. Descarga [AetherioNative-debug.apk desde GitHub Releases](https://github.com/Panoli707/aetherio-native/releases/download/native-v0.1.0-preview.1/AetherioNative-debug.apk).
2. Abre el gestor de archivos del dispositivo y entra en **Descargas** o **Downloads**.
3. Toca `AetherioNative-debug.apk`.
4. Si Android lo solicita, permite **Instalar aplicaciones desconocidas** únicamente para ese gestor de archivos. El nombre de la opción puede variar según el dispositivo.
5. Regresa al archivo, pulsa **Instalar** y después **Abrir**.
6. Si lo deseas, revoca al terminar el permiso de instalación del gestor de archivos.

Comprueba que la descarga corresponde al repositorio `Panoli707/aetherio-native`. Si el enlace no funciona, consulta la sección [Releases](https://github.com/Panoli707/aetherio-native/releases).

No necesitas root, desbloquear el bootloader ni activar la depuración USB. No desactives Play Protect; si Android bloquea el archivo, detén la instalación y comprueba su procedencia.

## Si ya tienes AetherioMobile

Esta aplicación se instala **junto a AetherioMobile**: no lo actualiza, no importa sus datos y no borra los datos de la aplicación anterior. No necesitas desinstalarla.

## Actualizaciones y datos

Este APK utiliza una firma de pruebas local. Una actualización compatible debe mantener el mismo identificador y la misma firma, además de una versión admitida por Android, para conservar los datos al instalarse sobre la aplicación.

Si Android informa de un conflicto de firma, **no desinstales para forzar la actualización**. Solicita un APK con la firma compatible.

El nombre y los favoritos se guardan en el dispositivo. Borrar los datos de AetherioNative o desinstalarla elimina esa información; no hay sincronización con una cuenta.
