## Antes de usar torrents

Tu IP puede ser visible para otros participantes y el consumo de datos/almacenamiento puede ser alto. La subida de contenido está desactivada, pero esto no anonimiza P2P. Usa solamente contenidos que tengas permiso para reproducir.

La disponibilidad depende de participantes, red y códecs del dispositivo. No hay transcodificación ni se garantiza compatibilidad universal con MKV, DTS/TrueHD o ASS complejos. HLS/DASH del selector se aplica solo a enlaces adaptativos HTTP. El motor upstream todavía está en desarrollo.

El soporte inicial es BTIH/v1; no se añaden archivos `.torrent` de usuario, descargas permanentes ni seeding en segundo plano. Al regresar a la app se reconstruye la sesión y se recupera la posición según el historial.
