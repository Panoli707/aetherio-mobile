# Aetherio 0.14.1 · Reproductor y ajustes visuales

Versión preliminar para Android 7.0 o posterior. Instala **Aetherio.apk** sobre la aplicación existente, **sin desinstalar ni borrar datos**. Se mantienen paquete y firma. Si Android indica un conflicto de firma o Play Protect bloquea el archivo, detén la instalación.

## Cambios

- Reproductor con controles translúcidos y distribución adaptable, controles de transporte centrales y menús conectados al estado real de reproducción.
- Paleta negra, blanca y violeta compartida en la interfaz.
- Las secciones de Ajustes se abren al primer toque.
- Encuadre y resolución de portadas ajustados para evitar ampliaciones excesivas.
- Historial de la rama antigua del selector integrado sin recuperar controles eliminados. Se conservan las tarjetas pulsables, filtros, metadatos y refresco superior derecho.
- README organizado como la versión de PC, con dependencias e instrucciones reales de Android. Retiradas referencias no obligatorias a terceros; se mantienen licencias, atribuciones y nombres técnicos necesarios.

## Verificación y límites

- La integración anterior al incremento de versión superó **47 pruebas Android** en emulador Android 14 y **210 pruebas JVM por variante**, con una prueba opcional omitida por variante.
- No se garantiza compatibilidad con todos los dispositivos, proveedores o códecs. No se ha probado esta actualización en un teléfono ARM físico ni con páginas de memoria de 16 KiB.
- Los torrents requieren participantes disponibles; tu IP puede ser visible y el consumo de datos y almacenamiento puede ser alto. Usa solo contenidos autorizados.
- El token de lectura TMDB sigue incorporado con la autorización existente: está ofuscado, no es un secreto irrecuperable.
- El código de Aetherio y del wrapper está disponible en la etiqueta. Se adjunta la fuente nativa fijada; consulta la procedencia y las licencias en `third_party/nuvio-engine/README.md`.
- Esta publicación no modifica ni despliega Workers.

Las siguientes actualizaciones se descargan desde **Ajustes > Actualizaciones**. Android siempre requiere confirmar la instalación.
