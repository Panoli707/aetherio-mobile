# Aetherio 0.14.3 · Desplazamiento e imágenes

Versión preliminar para Android 7.0 o posterior. Instala **Aetherio.apk** sobre la aplicación existente, **sin desinstalar ni borrar datos**. Se mantienen paquete y firma. Si Android indica un conflicto de firma o Play Protect bloquea el archivo, detén la instalación.

## Cambios

- Eliminada una capa gráfica de pantalla completa que se creaba incluso cuando no había ningún desenfoque activo. El desenfoque se mantiene al abrir las fuentes de reproducción, no durante la navegación normal.
- Eliminado el fundido de entrada de cada imagen del catálogo para reducir dibujos adicionales durante el desplazamiento. Se mantienen la resolución solicitada, el filtrado, el ancho de las portadas y sus proporciones.
- La carga de una portada ya no cambia el tamaño de su propia petición de decodificación cuando se conoce la proporción real. El tamaño de dibujo puede ajustarse una vez, pero no inicia otra carga por ese ajuste.
- Al salir una cabecera del área visible y volver a ella, se conservan su proporción y la fuente de imagen que funcionó, evitando repetir la cadena de alternativas.
- El carrusel de destacados se pausa durante los gestos y el desplazamiento vertical, y cuando queda fuera de pantalla. Antes de volver a avanzar espera ocho segundos de inactividad; no interrumpe un desplazamiento manual del carrusel.
- Reutilización de las tarjetas y de la lista ordenada de emisiones cuando sus datos no han cambiado.

## Verificación y límites

- APK final **0.14.3**, código **24**, optimizado con R8 y sin configuración de depuración. Firma compatible, alineación `zipalign -P 16` y ausencia del token en texto plano verificadas.
- **214 pruebas JVM aprobadas y una omitida por variante**, tanto debug como release; lint de ambas variantes completado.
- **27 pruebas de imágenes, Inicio y emisiones aprobadas**, incluidas las regresiones de carga duplicada, restauración de altura y pausa del carrusel. Las dos pruebas de navegación de Ajustes también pasan; la de restauración necesitó una repetición aislada tras fallar en la ejecución conjunta. No se ha modificado esa prueba para forzar su resultado.

Comparación diagnóstica de los APK release 0.14.2 y 0.14.3 en el mismo emulador Android 14 x86_64, con GPU del equipo y la misma ficha de anime (identificador de prueba `2545b172`). Se muestra el percentil 95 de duración de fotogramas; menor es mejor:

| Recorrido | 0.14.2 | 0.14.3 |
| --- | ---: | ---: |
| Inicio, primera pasada | 395,79 ms | 239,74 ms |
| Inicio, pasada posterior | 156,26 ms | 170,11 ms |
| Emisiones, desplazamiento horizontal | 132,20 ms | 155,43 ms |
| Ficha, primera pasada | 218,07 ms | 179,41 ms |
| Ficha, pasada posterior | 194,22 ms | 133,75 ms |

Los resultados son mixtos: no demuestran una mejora general del carrusel ni la eliminación de todos los tirones. Son una única comparación secuencial, sensible a la caché, la red y la carga del equipo; no equivalen al rendimiento de un teléfono físico ni garantizan 60 fps. Se descartaron las mediciones con renderizado por software por bloqueos de la interfaz del emulador. Queda pendiente confirmar el caso del vídeo en el teléfono original.

Se conservan las imágenes originales y sus alternativas de mayor calidad. El rendimiento y la nitidez también dependen del tamaño y la disponibilidad de las imágenes de cada proveedor.

Se adjunta la fuente nativa fijada y se conservan las licencias y atribuciones. Esta publicación no modifica ni despliega Workers.

Busca la actualización en **Ajustes > Actualizaciones**. Android siempre requiere confirmar la instalación.
