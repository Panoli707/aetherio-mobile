# Aetherio 0.21.0 · Mi espacio, listas de anime y descargas

Versión preliminar para Android 7.0 o posterior. Instala **Aetherio.apk** sobre la versión existente, **sin desinstalar ni borrar datos**. Se mantienen paquete y firma; si Android indica un conflicto de firma, detén la instalación.

## Mi espacio

- **Perfil local** abre Mi espacio, con banner, avatar, nombre y acceso a descargas. No se añade otro apartado de actualizaciones ni controles de fuentes, tipografías o motores que Aetherio no implementa.
- **Editar perfil** permite cambiar el nombre, elegir avatares y fondos integrados o importar imágenes de la galería. Las imágenes se copian al almacenamiento privado, se limitan y se corrige su orientación. No se requieren permisos generales sobre la galería ni se aceptan URLs arbitrarias de imágenes.
- La personalización local no se sustituye por el perfil de una cuenta conectada. El nombre anterior se conserva al actualizar.

## AniList y MyAnimeList

- Autorización en el navegador mediante los clientes registrados para Aetherio: flujo móvil oficial de AniList sin secreto y OAuth con PKCE para MAL nativo. Retornos exactos `aetherio://oauth/anilist` y `aetherio://oauth/mal`, con estado aleatorio, caducidad y protección frente a retornos repetidos.
- Tras conectar, cada servicio muestra su propio avatar, nombre, estado, actualizar, desconectar y categorías con contadores de la lista recibida. Favoritos se muestra en AniList; la API oficial de MAL utilizada no proporciona esa categoría.
- Puedes abrir una ficha desde la lista, editar estado, episodios y puntuación, o añadir una entrega desde **Gestionar listas de anime** en una ficha con equivalencia confirmada. Las entradas sin correspondencia AniList/MAL siguen visibles en MAL, pero no se vinculan a una ficha inventada.
- **Revisar sincronización del progreso local** compara los episodios consecutivos vistos con la entrada remota por ID y numeración de entrega. Cada modificación se revisa antes de enviarla. Antes de escribir se vuelve a consultar el estado remoto: si cambió, se muestran los datos nuevos sin sobrescribirlos. Los servicios no ofrecen escrituras condicionales atómicas; un cambio externo exactamente simultáneo no puede descartarse por completo.
- **Importar progreso remoto a Aetherio** añade el anime a la biblioteca y marcas de visto hasta el contador confirmado. No borra marcas existentes ni inventa posiciones de reproducción. No transfiere listas de una cuenta a la otra ni sincroniza películas o series no anime, imágenes o archivos descargados.
- Los tokens y las copias de las listas se cifran con Android Keystore. MAL renueva sus tokens y guarda la rotación; AniList requiere nueva autorización al caducar. Desconectar borra las credenciales y la lista local de ese servicio, no la cuenta ni su lista remota. Para revocar además el permiso del servidor, usa los ajustes del servicio.

## Descargas

- Las películas tienen **Descargar película**. En series, el botón junto a **Temporada** abre la selección por lotes: selección individual, seleccionar/deseleccionar todo y contador. También puedes descargar desde las acciones de un episodio.
- Tras seleccionar episodios, se elige una fuente real para cada uno. Puedes omitir un título sin fuentes y continuar con los demás. No se inventan calidades, idiomas, servidores ni velocidades; se utilizan los datos de las fuentes disponibles.
- **Mi espacio > Descargas** permite consultar la cola, pausar, reanudar, reintentar, elegir el archivo de un torrent ambiguo, reproducir lo completado y eliminar archivos. No se duplican tareas del mismo episodio o película.
- Cola persistente de **una descarga a la vez, en redes no medidas (normalmente Wi-Fi)**. Android puede posponer o detener el trabajo por restricciones de red, batería, espacio o cuotas de segundo plano. Forzar la detención desde Android impide continuar hasta volver a abrir la aplicación.
- Se admiten archivos HTTP compatibles, HLS/DASH bajo demanda sin DRM y torrents v1 compatibles con el motor existente. Para adaptativos se guardan las pistas seleccionadas por Media3 para el dispositivo, no todas las variantes del manifiesto. No se admiten emisiones en directo ni se eluden protecciones DRM.
- Los subtítulos externos de addons no se descargan; se conservan las pistas incluidas en el archivo o en la selección adaptativa. Un enlace que caduque puede requerir eliminar la tarea y seleccionar una fuente nueva.
- Una respuesta HTTP 403 con página HTML se informa como enlace no disponible, sin reintentos de conexión inútiles.
- Las descargas se conservan en almacenamiento privado, separado de la caché temporal de reproducción. No aparecen como archivos exportados en la carpeta pública Descargas. Desinstalar la app o borrar sus datos las elimina; borrar solo la caché no elimina los vídeos completados.
- Los bloques HTTP se reutilizan solo si existe un validador estable del servidor; sin él, un reintento reinicia esa transferencia para no mezclar versiones. La reproducción offline usa solo los bloques guardados y no recurre a la red si faltan.
- Las descargas torrent usan una sesión separada, conservan la subida de contenido desactivada y cierran el motor al terminar o pausar. La IP sigue siendo visible en P2P. Usa únicamente contenido que tengas permiso para descargar.

## Verificación

- `verifyRelease` completó compilación optimizada, lint y **355 pruebas JVM** (ningún fallo, dos pruebas opcionales omitidas).
- En Android, seis pruebas de descargas cubrieron HTTP, HLS, DASH, torrent, pausa/reanudación y un HTTP 403 con página HTML que ya no se reintenta. Las pruebas de perfil, imágenes, historial y seguridad de cuentas también pasaron.
- En el APK optimizado final se instaló sobre debug sin borrar datos. La tarea pausada se conservó, se reanudó con WorkManager, descargó 4 372 373 bytes, reprodujo el vídeo con Wi-Fi y datos desactivados y se eliminó; la lista de QA quedó vacía y el nombre local se restauró. Se verificó la firma compatible.
- Las pruebas controladas no equivalen a haber iniciado sesión con cuentas personales en AniList o MAL ni a comprobar todos los proveedores o dispositivos.

## Actualización

Se conservan biblioteca, historial, nombre local y preferencias anteriores. No se despliegan servidores ni servicios externos: la cola usa WorkManager dentro de la app. Los IDs OAuth son públicos; no se incorporan secretos OAuth ni tokens personales.
