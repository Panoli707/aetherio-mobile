# Aetherio 0.22.0 · Descubrir, biblioteca y arte de episodios

Versión preliminar para Android 7.0 o posterior. Instala **Aetherio.apk** sobre la versión existente, **sin desinstalar ni borrar datos**. Se conservan el paquete, la firma y el código de versión compatible con las instalaciones actuales.

## Biblioteca y descubrimiento

- La biblioteca incorpora controles de filtrado y una vista para explorar catálogos compatibles, con carga paginada y estado conservado al navegar.
- Las consultas de descubrimiento y los filtros se validan en el repositorio; errores de red o respuestas inválidas no se convierten en resultados vacíos que parezcan correctos.
- Se amplía la integración de temporadas, identidades y equivalencias de series para reducir asociaciones ambiguas entre proveedores.

## Arte y temporadas

- Las imágenes de episodios se muestran en fichas, historial, descargas y otras vistas que disponen de una identidad compatible.
- Se amplía y normaliza el catálogo local de logos de anime, con procedencia, auditoría y validación de recursos; cuando no hay una identidad inequívoca se conserva una alternativa segura.
- Se actualizan asignaciones de temporadas y episodios; no se infieren IDs a partir de coincidencias de título ambiguas.

## Personalización y estabilidad

- Mi espacio permite elegir y previsualizar colores de tema, manteniendo las preferencias locales.
- Se añaden mediciones internas de carga de imágenes para diagnosticar rendimiento sin registrar URLs, tokens ni datos de cuenta.
- Las pruebas de Android quedan fijadas al Xiaomi de QA y evitan que las tareas instrumentadas desinstalen la app o borren sus datos.

## AniList

- Se usa el flujo implícito oficial para aplicaciones móviles. El Worker devuelve una autorización sin enviar `redirect_uri` en la solicitud, lee el token únicamente desde el fragmento en el navegador y lo entrega al deep link de Aetherio.
- La app valida `state`, tipo de token, caducidad y parámetros duplicados antes de guardar la credencial cifrada. El token no se envía al Worker ni se escribe en logs.
- MyAnimeList conserva su flujo OAuth con PKCE.

## Verificación

- Pruebas unitarias JVM y pruebas del Worker verifican el protocolo OAuth, las respuestas, la seguridad de tokens, la carga del catálogo y el comportamiento de la biblioteca.
- La compilación de distribución verifica paquete, firma compatible, versión, metadatos de actualización y contenido del APK.
- La autorización de AniList debe probarse con la aprobación explícita del titular de la cuenta en el dispositivo; las pruebas automatizadas no sustituyen una sesión personal.

## Actualización

Se mantienen los datos de la aplicación al instalar sobre la versión existente. No desinstales ni borres los datos. El APK conserva la firma utilizada por las versiones anteriores.
